# Security

Please report suspected vulnerabilities privately. Do not open a public issue or
include exploit details, pack content, credentials, or customer data in public.

Private reporting contact: **pending-owner**. The owner must designate and publish
an approved private reporting channel. No email address or response SLA is implied.
If GitHub private vulnerability reporting is enabled for this repository, use its
Security tab to submit a private report; otherwise wait for the approved channel.

This initial version has no production release or support commitment. Verify only
immutable local pack trees with independently obtained publisher keys. A signature
does not establish commercial entitlement, legal approval or content correctness.
